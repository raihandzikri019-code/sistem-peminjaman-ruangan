# Sistem Peminjaman Ruangan

## Deskripsi Project

Sistem Peminjaman Ruangan adalah aplikasi berbasis web yang digunakan untuk mengelola proses peminjaman ruangan secara terkomputerisasi.

Aplikasi ini membantu pengguna dalam melakukan pengajuan peminjaman ruangan serta membantu pengelola dalam mengelola data ruangan, melakukan persetujuan peminjaman, dan melihat laporan peminjaman.

## Tujuan Aplikasi

Tujuan dari aplikasi ini adalah:

- Memudahkan pengguna dalam mengajukan peminjaman ruangan.
- Memudahkan pengelola dalam mengelola data ruangan.
- Membantu proses persetujuan peminjaman.
- Menyediakan informasi status peminjaman.
- Menyediakan laporan data peminjaman ruangan.

## Struktur Sistem

Aplikasi terdiri dari beberapa bagian utama:

1. **Login**  
   Digunakan untuk masuk ke dalam sistem.

2. **Dashboard**  
   Menampilkan ringkasan data peminjaman dan ruangan.

3. **Data Ruangan**  
   Digunakan untuk mengelola data ruangan yang tersedia.

4. **Data Peminjaman**  
   Digunakan untuk mengajukan dan mengelola peminjaman ruangan.

5. **Persetujuan**  
   Digunakan untuk menyetujui atau menolak pengajuan peminjaman.

6. **Laporan**  
   Digunakan untuk melihat rekapitulasi data peminjaman dan mencetak laporan.
